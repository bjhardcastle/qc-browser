# QC/

Built site of the QC rating app: https://bjhardcastle.github.io/qc-browser/

Rate dynamic-routing QC images (pass/fail) from `s3://aind-scratch-data/dynamic-routing/qc/`. Press `?` in the app for keys.
To share ratings, see settings → *Sharing ratings* (Google Sheet via [apps-script.js](apps-script.js)).
